# Urban Bloom Florist Website (Assignment 2b)

## Project Overview
A fully responsive, six-page front-end business website developed for Urban Bloom Florist, an independent boutique flower shop in Auckland, New Zealand.

## Repository Structure
* `index.html` - Home page
* `flowers.html` - Product catalogue with interactive category filtering
* `weddings.html` - Weddings and event services page
* `corporate.html` - Corporate floral subscription services
* `delivery.html` - Delivery information and FAQs
* `contact.html` - Enquiry form with client-side validation and mailto draft integration
* `css/style.css` - Global stylesheets, custom properties, and responsive grid layouts
* `js/script.js` - Interactive filtering, mobile menu toggle, and form validation logic
* `images/` - Curated and optimized Pexels floral photography assets

## How to Run Locally
1. Clone or download this repository.
2. Open `index.html` in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari). No local server or database is required.
